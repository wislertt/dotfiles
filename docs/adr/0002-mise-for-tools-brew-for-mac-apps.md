# mise installs tools; Homebrew installs only macOS GUI apps, from a Brewfile

Every command-line tool comes from mise, so Setup is the same on any platform. GUI apps (Orca, Zed, Docker) are macOS casks that mise cannot install, so they live in a `Brewfile` (`src/lib/Brewfile`, not linked), applied only on macOS, and never with `brew bundle --cleanup` because that would remove apps installed by hand. A tool lives in exactly one of the two. We considered mise-only with a manual "install by hand" list (rejected: apps would be unreproducible) and Brewfile for everything (rejected: it ties the whole setup to Homebrew).

Casks float, so `Brewfile.lock.json` is not written, and mise tools float at `latest` too (pin one in `mise.toml` only when a release breaks it; no `mise.lock`, the rare drift is caught by the weekly Fresh-machine job). mise's default `minimum_release_age` of 24 hours holds back a new `latest` release, and the npm and PyPI dependencies it pulls in, until it is a day old, so a compromised release has time to be caught. We rely on the default rather than set a week, which would delay fixes too; exempt one tool with `minimum_release_age_excludes`, or one run with `--minimum-release-age 0s`. `bake update` upgrades them. Setup installs mise tools without upgrading them; Update upgrades. Homebrew holds nothing but what the Brewfiles declare, so Setup and Update run only `brew bundle`, never bakelib's blanket `brew upgrade`. The one formula allowed in a Brewfile is `brew "mise"`: mise is the bootstrap, installed by hand before Setup can run, and listing it lets Update upgrade it.

Setup and Update never remove anything. Moving a tool to mise leaves the old copy where it was: `bake duplicates` lists copies of declared mise tools elsewhere on `PATH`, matching by the binary names the mise copy ships, and removes nothing. We considered a command that uninstalled through each package manager (rejected: one adapter and parser per manager is a maintenance burden for a job done once per tool, and `PATH` shows which copy actually runs). Superseded by ADR 0003: `bake tidy` now removes Strays, and a copy of a declared mise tool is one kind of Stray.
